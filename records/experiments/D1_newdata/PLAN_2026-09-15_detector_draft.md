## 트랙 1 — 작은 병변을 찾는 검출기 (주 트랙 · GPU)

### 1-1. train 원본 영상 복구 (CPU · 30~60분)
09-10 정리로 train 원본(`dataset/TopAneu/images`)과 722 전처리 캐시가 지워졌다. 검출기 재학습에 필요.
- 조직위 배포처에서 train 291 영상만 재수신(≈9GB, 7.9MB/s).
- `code/TopAneu-26/topaneu_release/images/*.sha`(sha256)로 전수 검증. 디스크 여유 167GB.

### 1-2. 사전 진단 — 설계 전에 신호가 있는지 (GPU 1~2시간 · val 만)
기존 E9 P5 fold_5(= 공식 split, 개정판 데이터) 로 val 41 을 `--save_probabilities` 추론.
val 의 작은 병변(8) 과 대조군(병변 없는 혈관 볼록부)에서 동맥류·혈관 확률 분포를 잰다.
- 동맥류 확률이 작은 병변에서 대조군보다 높다(순위 신호 존재) → 1-3a(독립 채널)가 살릴 여지.
- 둘 다 ≈0 → 1-3a 기대 낮음, 1-3b(표본 추출) 우선.
(test 는 보지 않는다. POSTMORTEM 9/7 의 "0.000~0.457" 은 test 5케이스 탐색치라 설계 근거로 쓰지 않는다.)

### 1-3. 변형 fold0 학습 — 레버 하나씩, 대조군은 기존 P5 fold_5
대조군: `nnUNetTrainer_250epochs · ResEncL iso0.4 · Dataset722(배경/혈관/동맥류)` fold_5 체크포인트(e9_bundle_experiment).
같은 split·같은 epoch·같은 전처리에서 **한 가지만** 바꾼다. GPU 2장에 하나씩 병렬.

| 실험 | 레버 | 가설 |
|---|---|---|
| **A8** 독립 채널 | nnU-Net region-based: 영역 {혈관 = 라벨1∪2, 동맥류 = 라벨2}, sigmoid | 동맥류가 혈관과 softmax 경쟁을 안 하면 작은 동맥류가 혈관에 먹히지 않는다 |
| **A9** 작은 병변 표본 | 패치 추출 시 3mm 미만 병변 주변을 우선 추출(전경 과표집을 크기 조건부로) | 작은 병변은 패치에 드물게 들어가 학습 신호가 약하다 |

(고해상도 입력은 뺐다 — 현 레시피가 이미 iso 0.4mm.)
시간: 학습 로그가 지워져 실측 없음. MASTER.sh 기록상 5폴드 18h/GPU2장 → **폴드당 약 7~9시간 추정**.
등록: 시작 전 `experiment_lineage.json` 에 A8·A9 계보 추가(PROJECT_RULES.md 3-1).

### 1-4. fold0 판정 — 검출기 단독 · 시드 무관 (`detcmp.py`)
val 42병변에서 대조군 대비: 작은 병변 커버 · 전체 커버 · 거짓 blob/케이스.
**val 작은 병변이 8개뿐**이라 fold0 은 "망가지지 않았나 + 방향" 확인용이다.
- 진행: 전체 커버 대조군 이상 ∧ 거짓 blob/케이스 증가 ≤ +0.10 ∧ 작은 병변 커버 대조군 이상.
- 둘 다 통과하면 작은 병변 커버가 더 높은 쪽 하나만 1-5 로.

### 1-5. 본 판정 — 5폴드 OOF 커버리지 (GPU ≈1.5~2일)
변형을 폴드 1~4 까지 학습하고, 대조군 P5 폴드 6~9 와 함께 각 폴드 validation 케이스를 추론해
**train∪val 332케이스 OOF** 로 비교한다(작은 병변 표본이 수십 개로 늘어 판정력이 생긴다).
- 채택 조건(고정): 작은 병변 OOF 커버 순증 ≥ +5병변 ∧ 부호검정 p < 0.05 ∧ 거짓 blob/케이스 증가 ≤ +0.10.

### 1-6. e2e (GPU 추론 수 시간 + CPU)
통과한 검출기 5폴드 앙상블 → 기준 분류기(개정판 학습표 · gC ON · 패치필터) → 트랙 0 판정 장치로 test·val.
- ⚠ 폴드 1~4 는 공식 val 을 학습에 쓴다. **val e2e 는 fold0 단독 모델로**, test e2e 는 앙상블로 잰다.
- ⚠ 채택되면 제출본 기준 누적 diff 를 `~/SUBMISSION/APPLY_CHANGES.md` 에(PROJECT_RULES.md 0장). T4 7분 런타임 재확인.
