# C26 — ICA·마진 게이트 2등조각 방출 (gC) · 채택 ★

31번째 시도에서 첫 채택. 규칙(test+ AND val+, 사전 고정) 을 10/10 시드로 통과.

## 방법
1등 예측이 ICA(3.x) 이고 p2/p1 > 0.7 인 병변만, 2등 클래스에 blob **중심 3복셀**을 방출.
나머지 복셀은 1등 유지. 잘 맞히는 클래스(중대뇌·Acom, 20+표본)는 절대 건드리지 않는다.

## 왜 되나
- 공식 TP 판정 = intersection > 0 (1복셀). 케이스·클래스당 0/1 플래그.
- FP 1개 비용(-0.0911 class-MCC) vs TP 1개 이득(+0.798) → 손익분기 2등적중 10.2%.
- ICA+마진0.7 부분집합의 2등적중 = 292 0.270 / test 0.412. 분기점의 3~4배.
- 292 와 test 가 **같은 방향을 가리킨 유일한 축** (클래스군별 2등적중).

## 주의
지표 구조(1복셀 TP·존재 플래그)를 이용하는 다중 후보 방출이다. 예측이 좋아진 게 아니다.
발표·문서에는 "ICA 한정 top-2 후보 방출"로 정직하게 기술할 것.
후속: fin = gC + RF_TREES 1500 (q10) 검증 중.
