## 1. 가장 큰 상금은 막혀 있다 — 먼저 뚫는다

분류 오답의 **40%가 ICA C6/C7 세부분절**이다. 완벽히 맞히면 전체 정답률 69.0% → 81.3%.
그런데 혈관 라벨에 `ICA-C6-C7` 이 **한 덩어리**라 세부분절 정보가 아예 없고, 곁가지
분기점은 절반만 잡힌다(OA 56% · Pcom 48% · AChA 48%).

김지수 님이 C6/C7/terminus 를 나눠 재라벨링했고 "ICA 부분만 채점 시 0.2 정도 상승" 이라 한다.
**착수 전에 확인해야 할 두 가지** (이게 안 풀리면 재학습은 도박이다):

1. **채점 GT 가 무엇이었나.** 재라벨링한 GT 로 채점했다면 점수 상승이 "모델이 좋아져서"가
   아니라 **"GT 가 모델 쪽으로 움직여서"** 일 수 있다. 대회 공식 GT 엔 그 수정이 없다.
   → 질문: **재라벨링 전 GT 로 채점해도 올랐나?**
2. **학습 케이스까지 재라벨링됐나.** test 몇 건만 고쳤다면 혈관 모델을 재학습할 수 없다.
   → 필요한 것은 **train 292 케이스의 ICA 라벨**.

**데이터를 받으면 즉시 — 상한 실험 (학습 없음, 반나절)**
수정된 GT 혈관을 **예측 대신 그대로** 분류기에 먹여 ICA 정답률을 잰다.
"혈관 분할이 ICA 에서 완벽하다면 얼마나 오르나" 의 상한.
- 64% → 90%대 → **재학습 확정.** 12.3%p 가 실재한다
- 거의 안 움직임 → 병목은 라벨이 아니다. 재학습도 모듈도 헛수고

GPU 수백 시간짜리 재학습을 걸기 전에 이 한 번을 반드시 먼저 한다.

## 2. 값싼 결정적 측정 — M1 길이 전수조사 (H6 직후 · 30분)

V1-A 와 V1-B 의 **공통 전제**. 분류기를 안 건드리므로 다른 실험과 독립.

**왜**: 5.2 early bifurcation 과 5.3 M1-M2 junction 은 **해부학적으로 같은 사건**(M1 이 M2 로
갈라짐)이고 차이는 **그 갈라짐이 M1 의 어디쯤인가** 뿐이다. 그런데 현재 피처는 거리를
**두개 크기**로 나눈다. 분모가 틀렸다 — 기준은 **그 환자의 M1 길이**여야 한다.
실측: 종말부까지 정규화거리 5.2 = 0.395±0.114 · 5.3 = 0.686±0.158,
**5.2 표본의 57% 가 5.3 범위 안에 들어간다.**

**표본을 40배로 늘린다**
```
나쁜 설계: 병변 14개(5.2) vs 51개(5.3) 에서 임계 탐색      ← 과적합
이 설계:   train 292케이스 × 좌우 = 584개 M1 길이로 정규분포를 만들고
           "하위 N 퍼센타일 = early" 로 정의                ← 임상 정의 그대로
```
임계가 **병변 라벨과 독립적으로** 정해진다. 라벨을 보고 고르는 게 아니므로 과적합할 대상이 없다.
그다음 그 임계가 실제 5.2/5.3 을 얼마나 가르는지는 **탐색이 아니라 검증**이다.

⚠ **선례**: C60 §19 — 292 케이스 전수로 게이트 임계를 골랐더니 train 우위 +4 → test 0 · val −1.
목적함수를 바꿔 재탐색해도 같았다. **라벨을 보고 임계를 고르면 292 로도 과적합한다.**

**임계 실재 조건 (train 292 에서만 판정 · test/val 안 봄)**
```
1. AUC ≥ 0.90            단일 축으로 갈린다
2. 겹침 구간 표본 < 20%   회색지대가 좁다
3. 좌우 각각 성립         한쪽만 되면 우연
셋 다 만족 → 룰/피처 가능.  하나라도 미달 → 겹침은 생물학적이고 이 축을 닫는다.
```

## 3. 네 축 — 영역마다 병목이 다르므로 수단도 다르다

| 실패 | 전체 오답 중 | 병변 | 원인 | 수단 |
|---|---|---|---|---|
| ICA C6/C7 | **40%** | 다수 | 곁가지 분할 커버리지 48~56% | 혈관 재라벨링(§1) |
| 후순환 1.x | **28%** | 4 | **학습표본 1~2개** | **가드된 룰** (V1-B) |
| **≥10mm 거대** | **13%** | 8 | **중심점 ≠ 목** | **목 기준 위치** (V1-D) |
| 5.2 ↔ 5.3 | 9% | 3 | **분모가 두개크기** | 호길이 `len_m1` (V1-A) |
| 5.1 ↔ 3.7 | 3% | 1 | 거대 건과 동일 | V1-D 에 포함 |

- **피처는 표본이 있어야 배운다.** 후순환 실패 3클래스는 학습표본이 각 **1개**다.
  무슨 피처를 줘도 RF 는 결정경계를 못 만든다. **룰은 표본 0개여도 된다.**
- **룰은 측정값이 있어야 작동한다.** ICA 는 곁가지 분기점이 절반만 잡히니 룰도 못 쓴다.
- 5.1↔3.7 은 독립 항목이 아니다. **거대 동맥류 문제의 부분집합**이므로 따로 손대지 않는다.

### V1-D · 목 기준 위치 (우선순위 1 — 가장 싸고 독립적)

**왜**: 임상에서 동맥류 위치는 **목**(낭이 모혈관에서 나오는 자리)으로 정의되는데, 우리는
**낭의 중심점**으로 위치시킨다. 작은 낭은 중심 ≈ 목이라 무해하지만, 15mm 낭은 중심이
목에서 7mm 넘게 벗어난다 — M1 전체 길이가 9mm 인데.

실측: **≥10mm 정답률 48%** (다른 구간 68~80%). 전시드 오답 4건이 전부 "몸통/끝 클래스가
인접 접합부나 반대쪽으로 끌려감" 이다. 낭이 여러 분절을 덮어 겹침 피처가 포화된다.
학습표본 `L-5.1 M1 trunk`(n=1) 는 ICA 겹침 2998 · ICA↔M1 0.45mm 로 **3.7 과 구별 불가능한
서명인데 라벨은 5.1** 이다 — 표본 1개가 패턴을 정면으로 거스르니 RF 가 배울 게 없다.

**변경**: 피처 추출 시 위치 기준점을 `낭 중심` → `낭 ∩ 모혈관 영역의 중심`(목 근사)으로.
차원이 안 늘어난다 — **기존 피처의 입력 좌표만 바뀐다.**

**위험이 낮은 이유**: 작은 병변은 값이 거의 안 변한다(중심 ≈ 목). 지금 잘 맞히는
68~80% 구간을 건드릴 여지가 작다. 다만 **전 병변에 영향**이 가므로 e2e 로만 판정한다.

**판정**: e2e 5시드 test·val 동시 (6지표 중 ≥4 ∧ ΔMCC ≥ 0).
⚠ 표본 8개다. 이득이 나와도 신뢰구간이 넓다는 걸 결론에 명시한다.

### V1-A · MCA 호길이 피처 (우선순위 2 — 시험대)

§2 의 세 조건을 통과해야 착수. 피처 4차원, **MCA 밖은 전부 0**.
```
t_m1        M1 축 호길이 [0,1]   (ICA 종말부=0, M1-M2 분기=1)   → 5.1 vs 5.2·5.3
len_m1      M1 측지길이 / 두개 스케일                          → 5.2 vs 5.3
t_from_end  1 - t_m1
is_m1       축 성립 여부 (0/1)
```
`len_m1` 이 핵심이다 — **병변이 아니라 혈관의 성질**이므로 병변 중심이 어디 찍혔는지와
무관하다. 지금 쓰는 `종말부까지 거리` 는 병변 위치에 흔들린다(큰 낭일수록 심함).

**대상 밖은 0** 설계를 반드시 유지한다. `row_to_vec` 은 블록마다 재정규화하므로 0 블록은
벡터를 안 바꾼다 → 다른 클래스에 잡음이 안 들어간다.
(C34 가 전 혈관에 얹어 e2e −0.0228 로 기각된 원인이 이것이다.)

**판정 2단**: ① CV 선별 `ΔMCA ≥ +3.0%p ∧ Δmacro ≥ −1.0%p` → ② e2e 5시드 test·val 동시.

⚠ **MCA 는 상금이 아니라 시험대다.** 오답 전체가 병변 5개, 호길이 대상은 3개다.
앵커가 98~99% 로 가장 깨끗하므로 **여기서 안 되면 어디서도 안 된다** 는 판별 목적이다.

### V1-B · 후순환 가드된 룰 (우선순위 3 — 가장 위험)

대상: `1.9 BA-SCA junction`(좌우 각 0/5) · `L-1.3 VA-PICA junction`(0/10). 전부 학습표본 1개.
분기점은 잡힌다(SCA 81~85% · PICA 76~77%) — **피처가 아니라 표본이 없는 것**이므로 룰이 맞다.

```
BA 축에서  t_SCA = SCA 분기 위치
   병변 t 가 [t_SCA − m, t_SCA + m] 안이면 → 1.9 BA-SCA junction
VA 축에서  t_PICA = PICA 분기 위치 → 1.3 VA-PICA junction
m 은 train 292 에서만 고른다.
```
**가드 — 무조건 덮어쓰지 않는다**
```
(a) RF 1등 확률 − 2등 확률 < TAU     애매할 때만
(b) RF 1등이 같은 축의 이웃 클래스    엉뚱한 데서 안 끌어옴
(c) 해당 분기점 노드가 그래프에 존재   측정값 없으면 손 안 댐
```
무조건 후처리는 금지 — 이미 맞히는 `1.10 BA tip`(67%) · `1.1 VA trunk`(67%) 를 망친다.
**손익 역전이 이 축의 최대 위험이다.**

**판정**: e2e 5시드 test·val 동시 + **안전 조건** — override 로 새로 틀린 건수 ≤ 새로 맞힌
건수 를 test·val 각각 확인.

⚠ 후순환 검출병변이 **18개**뿐이다. 0/10 도 병변 2개×5시드다. CV·단일 스플릿 금지.

### V1-C · ICA 호길이 재시도 (§1 이후)

**조건부 기각 상태.** 2026-09-11 CV: ΔICA +2.4%p · Δmacro +0.9%p → 기준(+3.0%p) 미달.
**미달 원인은 피처가 아니라 커버리지** — ICA 호길이가 만들어진 병변이 151/268 = **56%**.
혈관 재학습으로 커버리지가 오르면 **다시 잴 가치가 있는 유일한 피처 축**이다
(C34 와 달리 방향이 양수로 확인됐다). 산출물 보존: `arc_feat.py` · `arc_cv.py` · `arc/train/*.npz`.
