## 고정 사실 (재측정 불필요)

- 분기점 그래프·분류기의 mm 좌표는 **affine 이 아니라 `복셀인덱스 × 간격`**.
  affine 으로 변환하면 조용히 전부 실패한다.
- `gt_loc` 은 정수 id 가 아니라 **클래스 이름 문자열**. 미러 증강은 `mirror_name()`.
- `row_to_vec` 은 블록 concat 마다 전체 재정규화한다 → **0 블록은 벡터를 안 바꾼다.**
  이 성질 덕에 "대상 밖은 0" 설계가 다른 클래스를 오염시키지 않는다.
- `c5_location_v2.py` 를 직접 고치지 않는다. 다른 실험이 실행 중일 수 있다(bash·python 모두
  실행 중 파일을 다시 읽는다). **복사본을 만들어 쓴다.**
