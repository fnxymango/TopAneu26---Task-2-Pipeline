## 미측정 구간 (다음 실험의 근거)

② 는 **개정피처 위에서** 잰 gC 효과다. 개정피처는 ① 에서 미채택됐으므로, 제출본(구피처)에
gC OFF 를 얹었을 때 같은 이득이 나오는지는 **이 실험에 팔이 없다**.
필요한 팔: `b1off` = 구검출기 + **구피처** + gC OFF (+ 패치필터). 검출 추론 재사용 가능.
